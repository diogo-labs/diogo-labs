##  Featured Project

### Triangle Calculator Automation

Automation project developed using **Java**, **Selenium WebDriver**, **JUnit 5**, and the **Page Object Model (POM)**.

This project automates functional tests for different triangle calculators available on CalculatorSoup using the Page Object Model (POM).

### Main Features

- Automated functional testing
- Equilateral Triangle Calculator
- Isosceles Triangle Calculator
- Triangle Theorem Calculator
- Explicit Waits
- Reusable Page Objects
- Reusable BaseTest
- Data-driven test cases
- Clean and maintainable project structure
